# 路线图

PowerLock 的定位：**插电时自动保持 Mac 在线（不锁屏、合盖继续运行），拔电后自动恢复系统默认**，不需要每次手动开关。功能保持少而稳，优先保证"拔电一定恢复"。

## 已完成

- 1.0：菜单栏 App + root 后台助手；插电不锁屏、插电合盖运行、拔电恢复；一键卸载；GitHub Releases、Homebrew tap、源码构建
- 1.2：新图标和菜单栏图标；菜单重新设计（状态区、总开关、更多子菜单）；新的首次引导和关于窗口；英文界面
- 1.1：合盖时拔电立即睡眠；只撤销自己设置的 `disablesleep`；升级后提示更新助手；`brew uninstall --zap` 清理助手；退出 App 时恢复屏幕保护和显示器休眠

## 计划中

| 优先级 | 内容 | 说明 |
|---|---|---|
| 高 | 公证（Developer ID + notarization） | 去掉首次打开的"无法验证开发者"提示，也是进入 homebrew/cask 官方仓库的前提 |
| 中 | 助手改为事件驱动 | 目前助手每 5 秒检查一次电源；改成监听 IOKit 电源通知，拔电后立即恢复 |
| 中 | 签名后迁移到 `SMAppService` | 用系统的"登录项与扩展"管理助手和登录启动，用户可在系统设置里看到和关闭 |
| 低 | 熄屏但不锁屏 | 需要修改全局"需要密码"策略，风险较高，先收集需求 |
| 低 | 多用户 | 目前只跟随当前控制台用户 |

## 不做

- 电池供电时合盖运行：合盖后散热差、容易把电量耗光。需要这个功能可以用 [Sleepless](https://github.com/Aboudjem/Sleepless)
- App Store 版本：沙盒不允许修改 `pmset`
- 遥测与统计

有需求或问题请提 [Issue](https://github.com/pandengyao/PowerLock/issues)。
